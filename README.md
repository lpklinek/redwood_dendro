## 1. Overview

This repository contains data from dendrometers and meteorological stations at Big River Forest and Garcia River Forest. 

Users can download a zip file of the entire repository by clicking on the green `code` tab at the top of the page, and then clicking `Download ZIP`. Users with GitHub accounts can also `fork` the repository.


## 2. Organization 

The repository is organized as follows:

-   `Dendrometer` contains all raw dendrometer data. Files are named with the tree name (ex. 'BigRiverA') and the date of download.

-   `Met` contains two data files, one for each site's meteorological station. 


## 3. Data 

#### Dendrometer Data

Folder name: `Dendrometer`

Data was collected using Hise Scientific automated point dendrometers and data loggers. Data contained in this folder is unprocessed. 


#### Meteorological Data

Folder name: `Met`

Data was collected using a METER ATMOS 41 weather station and a METER ZL6 data logger.
Units and variable name for each column can be found in row 3 of each .csv file.
